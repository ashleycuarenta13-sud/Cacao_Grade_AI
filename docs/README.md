## Folder layout

Part F's project layout:

```
/frontend   Flutter Web client
/backend    FastAPI + Uvicorn API
/cnn_service  CNN inference service (the document calls this /ml-service)
/database   SQL migrations
/docs       this folder
/certs      TLS certificates generated by backend/make_cert.py
```

## Environment variables

Part F requires settings to live outside the source code, in a gitignored
`.env`:

| Variable | Purpose | Local default |
|---|---|---|
| `API_BASE_URL` | Public base URL of the API | `http://127.0.0.1:8000` |
| `DATABASE_URL` | PostgreSQL connection string | `postgresql://postgres:admin123@localhost:5432/cacao_gradeai` |
| `JWT_SECRET` | JWT signing key (also accepted as `CACAO_JWT_SECRET`) | generated into `backend/.jwt_secret` |
| `CLOUD_STORAGE_BUCKET` | Photo bucket when storage moves off local disk | unset - writes to `backend/uploads/` |
| `CNN_SERVICE_URL` | Inference service (also accepted as `CACAO_CNN_URL`) | `http://127.0.0.1:8001/predict` |

Copy `.env.example` to `.env` to start. `backend/envfile.py` reads it with the
standard library only - no added dependency - and an already-set variable is
never overwritten, so a platform's secret store always wins.

The Flutter client does not read `.env`; it takes its base URL at build time:

```bash
flutter run -d chrome --dart-define=CACAO_API=http://127.0.0.1:8000
```
